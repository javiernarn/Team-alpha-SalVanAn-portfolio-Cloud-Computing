== Description ==

The Ignite Agency Portfolio theme is designed with a structured layout for presenting projects, visual content, team information, services, and business details in a clear and organized manner. It includes responsive page layouts, customizable homepage sections, portfolio galleries, banner areas, and flexible content blocks that help manage information efficiently. The responsive design ensures content adapts to desktops, tablets, and mobile devices while maintaining consistency across screen sizes. The theme offers customization options for colors, typography, headers, menus, backgrounds, and page layouts through an intuitive settings interface. Additional features include blog integration, testimonial sections, social media connectivity, widget-ready areas, and contact form compatibility. Built with a clean code structure, the theme supports compatibility with commonly used plugins and follows modern development standards. Portfolio showcase sections allow projects and visual content to be organized effectively, while flexible templates support different content arrangements. Navigation elements are structured to improve accessibility and content discovery. The theme provides practical customization tools for managing visual presentation and content organization while maintaining responsive performance and usability across multiple devices and viewing environments.

== Installation ==
        
1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the ignite-agency-portfolio theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away
